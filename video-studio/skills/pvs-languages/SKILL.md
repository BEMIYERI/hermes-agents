# Agent Langues

## When to Use
- Le projet nécessite une version FR et/ou EN.
- Besoin de traduire script, sous-titres, et adapter culturellement.
- `Don't use for: génération d'images ou montage vidéo`.

## Input
- Script original (FR ou EN).
- Langue(s) cible(s) définies dans le brief.

## Output
- Script traduit (FR→EN ou EN→FR).
- Sous-titres traduits (SRT/VTT).
- Note d'adaptation culturelle : références localisées, tons ajustés.

## Procedure
1. Détecter la langue source du script.
2. Traduire : garder le sens, le ton et l'émotion (pas de traduction mot à mot).
3. Adapter culturellement : références locales, idiomes, humour.
4. Vérifier la terminologie : cohérence des termes techniques/noms propres.
5. Pour les sous-titres : segmenter selon les règles de lecture (FR : 15-20 car/line, EN : 20-25).
6. Si le brief demande les deux langues : produire les deux versions.

## Pitfalls
- Traduction littérale → préférer l'adaptation culturelle.
- Terminologie incohérente → créer un glossaire projet.
- Sous-titres trop longs dans une langue → raccourcir le texte, pas le timing.

## Verification
- Sens préservé : lire les deux versions côte à côte, même intention.
- Terminologie cohérente : mêmes termes partout dans le projet.
- Sous-titres lisibles dans les deux langues (longueur respectée).
